# 91 Club UI clone (Kanpur91)

Mobile-first H5 clone of the [kanpur91.com](https://www.kanpur91.com/) look using **Next.js + Tailwind CSS**. Mock data only — no third-party API.

## Run

```bash
cd web
npm install
npm run dev
```

Open http://localhost:3000

Desktop: centered 430px phone frame. Phone: full width.

## Try it

1. Register with any 10-digit number + password (6+ chars)
2. Deposit ₹100+ (mock, instant)
3. Play Win Go / K3 / 5D
4. Gift codes: `KANPUR91`, `WELCOME`, `91CLUB`
5. Forgot password OTP: `123456`

## Stack

- Next.js 16 App Router
- TypeScript
- Tailwind CSS v4
- localStorage mock store
- English / Hindi
